# 蓝色大肥鱼 · 名场面索引

把中文互联网上关于「**蓝色大肥鱼**」的名场面整理成**可离线浏览**的单页索引——DeepSeek 的蓝鲸 logo 被模型自己认成「蓝色大肥鱼」，后来长成了端着饭碗、上班摸鱼、嘴上傲娇的**鲸鱼娘 / DeepSeek 娘**。每一条都能看图、看原对话、看来龙去脉。

## 怎么用

下载 Release 里的 zip → 解压 → **双击 `index.html`**。

```
index.html      单文件页面（CSS / JS 全内联，数据驱动渲染）
assets/         本地资源：梗图与原始对话截图
```

图片全部本地存档，**离线打开也能完整显示**；只有条目内的出处链接需要联网。

## 分类规则

分类看**梗的触发源**——「什么直接引发了它」，不看作者、不看形式。

| | 类别 | 判定规则 |
|---|---|---|
| **A** | 用户对话 / 实测梗 | **唯一判定：是否由真实的 DS / DSH 使用过程产生。** 每条都必须能对应到一次具体的对话或使用记录（用户晒出的截图、思维链、行为日志），对应不上就不能进 A。 |
| **B** | DS 官方事件梗 | **必须能对应到一个具体的「DeepSeek 官方事件」**——由官方自己发出、有公告／有时间／可核对的动作（发版、灰度、调价、涨跌价、下线与撤回、事故），并包含由该事件衍生的各类创作。判定看触发源、不看作者：贴纸台词也可以是 B 类。 |
| **C** | 场外事件 | 由**社区内部的具体事件**触发——主角之争、投票、站子图库上线、二创生态与桌宠。同样要求「事件」而非「氛围」。 |
| **D** | 纯二创梗 | **既没有对应的使用记录，也没有对应的官方事件**——单凭印象编的台词与形象。 |

### 几条边界

- **只算「有关联」不算触发源**：官方发布 DeepSeek Harness 只是 dsh 梗的背景，真正触发它的是模型扫描用户目录时写下的真实思维链，所以 dsh 归 A。
- **状态归 D，事件归 B**：「官方一直很便宜」「按 token 计费」「lite / reasoner 分层」「高峰期卡顿」都是长期状态、不是事件，由它们衍生的梗归 D。
- **「官方相关」但无事件的不算 B**；不是官方动作引发的社区事件归 C。
- **跨界梗标注「主类 + 副类」**，不强行二选一（例：吃白饭系列主类 D〔印象式二创〕＋副类 A〔素材源头是干饭使用记录〕）。
- 反例一则：「真当我是便宜货啊」虽然是网友写的贴纸台词，但它对应 2026 年那次 API 调价公告（图右下角文字也在提涨价），因此归 **B** 而非 D。

## 证据等级（独立于分类）

分类管「梗从哪来」，证据等级管「**这句话是不是模型真的说过**」：

| 等级 | 含义 |
|---|---|
| 📷 原始内容 | 有原始对话 / 界面截图，按原界面逐字转录 |
| 🗣️ 原话引用 | 有原文引用，但未附原始截图 |
| 📰 转述 | 内容来自媒体或第三方转述，未找到原始截图 |
| 🎨 二创台词 | 网友为角色写的贴纸文案，**并非模型真实输出** |

图文对应关系绝大多数已逐张打开核对；只有少数需要特别说明来源或对应情况的条目，才会在卡片下方另行加注。

## 标题写法

- 以「」开头 = **原文截取**
- 不带引号 = **概述或演绎**（含谐音改写、拟写台词）
- B 类标题直接写官方事件本身并带时间锚点（例：`2026-05-22 永久降价`），梗由事件衍生，留在内容里
