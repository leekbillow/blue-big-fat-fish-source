分类规则与免责声明

① A 的唯一判定：是否由真实的 DS / DSH 使用过程产生——每条都必须能对应一次具体的对话或使用记录（截图 / 思维链 / 行为日志），对应不上就不能进 A。
② B 必须是「DS 官方事件」：由 DeepSeek 官方自己发出的动作才算——有公告、有时间、可核对（发版、灰度、调价、涨跌价、下线与撤回、事故等），并包含由该事件衍生的各类创作。不是 DS 官方动作引发的社区事件归 C；「官方一直很便宜」「按 token 计费」「lite / reasoner 分层」「高峰期卡顿」这类长期状态归 D——状态归 D，事件归 B。
③ 只算「有关联」不算触发源：官方发布 DeepSeekHarness 只是 dsh 梗的背景，真正触发它的是模型扫描用户目录时写下的真实思维链，所以 dsh 归 A。
④ 反过来，「真当我是便宜货啊」虽然是网友写的贴纸台词，但它对应 2026 年那次「计划近期整体上调 DeepSeek API 服务的定价」公告（图右下角文字也在提 API 涨价），因此归 B 而非 D。
⑤ 跨界梗标注「主类 + 副类」，不强行二选一（例：吃白饭系列主类 D〔印象式二创〕＋副类 A〔素材源头是干饭使用记录〕）。
⑥ 图文对应置信度：全部梗图与原始内容已下载到本地（assets/memes/ 与 assets/），整页可离线打开。图片与条目的对应关系绝大多数已逐张打开核对；只有少数需要特别说明来源或对应情况的条目，才会在卡片下方另行加注。
